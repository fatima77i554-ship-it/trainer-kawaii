# Тренер Лизи · кавайная версия

Кабинет тренера в Telegram (Mini App) — новая, милая версия [trainer-miniapp](https://github.com/fatima77i554-ship-it/trainer-miniapp),
собранная на Cozy UI Kit (спрайты Cozy UI Pack by dobo_ui).

## Главное правило: приложение не тревожит
- **Никакой статистики.** Нет доходов, процентов посещаемости, счётчиков пропусков, «была N дней назад».
- **Нет красного.** Статусы — мягкие пилюли: «Придёт», «Ждём ответик», «Не сможет», «Была ♡». Отмена — серая, не красная.
- **Бот заботится сам.** Вместо тревожных баннеров — записочка «Это нормально — бот сам напомнит. Тебе ничего не нужно делать ♡».
- **Можно передумать.** Отмена тренировки — через мягкий диалог, а потом ещё и кнопка «Вернуть».
- Абонемент — сердечками, а не цифрами «2 из 12».

## Экраны
Вкладки: Расписание · Клиенты · Настройки. Страницы: тренировка, перенос, новая тренировка, клиент, абонемент, приглашение в бота.

## Сборка
Нужна папка с китом рядом: `../cozy-ui-kit` (или укажи путь: `KIT=/путь/к/cozy-ui-kit`).

```bash
npm install
npm run build          # → docs/ (для GitHub Pages)
npm run build:single   # → single/trainer-kawaii.html (один файл для предпросмотра)
npm run dev            # → http://localhost:5174 с пересборкой
```

Интерфейс нарисован под ширину 600px и масштабируется под экран (`--zoom` на `html`).
Демо-время можно не подменять: данные строятся от текущей даты.

## Публикация
Адрес: **https://fatima77i554-ship-it.github.io/trainer-kawaii/** (GitHub Pages → ветка `main`, папка `/docs`).

Подключить к боту — в @BotFather:
1. `/mybots` → @Lizzi_trainer_bot → **Bot Settings** → **Menu Button** → **Edit menu button URL** → вставить адрес выше.
2. Если у бота настроено главное мини-приложение: **Bot Settings** → **Configure Mini App** → **Edit Mini App URL** → тот же адрес.

Сборка для публикации (`npm run build`) кладёт в `docs/assets` только спрайты из `tools/used-assets.txt`
и сжимает PNG (`tools/optimize_assets.py`). Добавили экран с новыми картинками — допишите их в список.

Имя тренера берётся из Telegram (`initDataUnsafe.user`): в приветствии — имя, в профиле — имя, фамилия и @ник.
Остальные настройки прототипа (username бота, адрес зала, часы записи) — в `src/data.ts`, объект `CONFIG`.
Палитра — `PALETTE.md`, анимации — `MOTION.md`.
